MY APPROACH

DESIGN PHILOSOPHY & CORE VALUES

Four foundational principles guiding every user experience, design system, and frontend interaction I create.

User-Centric First

Deep research and empathy precede every design layout. Understanding pain points, user flows, and accessibility ensures intuitive digital experiences.

Scalable Systems

Crafting structured Figma design tokens, modular component libraries, and UI kits for consistency and rapid engineering handoff.

Mobile-First Precision

Designing for smaller viewports first guarantees fast load performance, clear visual hierarchy, and flawless execution across desktop and mobile screens.

AI-Assisted Innovation

Combining design expertise with modern AI tools (ChatGPT, Claude, Copilot) to accelerate research, prototyping, and code iterations.
